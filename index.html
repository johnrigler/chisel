Start: what Chisel proves

        
This is the colleague-facing bridge between the older signing conversation, the 2020 crypto-linguistic white paper, and the current Chisel implementation. It now starts with the practical reason Chisel is vanilla JavaScript: elliptic gives the browser enough secp256k1 machinery to sign locally without turning the main app into a Node stack dependency tour.

        

          
            Read origin bridge
            Starts with vanilla JS, elliptic, local signing, QR stickers, mundane transaction UX, then maps the white paper kernel to Portal, MacDougall, ASC, and the current refactor boundary.
          
          
            Printable HTML
            Letter-friendly review copy with a print button and explicit page-break behavior.
          
          
            Refactor phases
            Low-risk sequence for cleaning up Chisel before touching signing, fees, UTXO selection, or broadcast code.
          
          
            What Chisel proves
            Short colleague-facing claim: local signing, ordered outputs, explorer/node resources, static graph, and satellite tools.

Current boundary

        
Core builds, signs, serializes, decodes, and explains meaningful UTXO transactions. The main app remains plain browser JavaScript. elliptic is part of the core signing path. Portal displays and filters transaction artifacts. Data is a static or local snapshot. fileProxy, bunOven, keeperBun, scanners, label tools, and importers are satellites.

      


      

        
First demo path

        
Start with why local browser signing matters, then open Portal, load a local or bundled transaction fixture, inspect ordered outputs, read MacDougall address lines, inspect OP_RETURN if present, treat amount codes as optional binders, then verify the raw JSON. Do not start with every historical experiment.

Examples

        
Runnable artifacts and reference outputs. These are examples of Chisel's portable-tool approach, not extra transaction modes.

        

          
            M64 artifact workbench
            Stage controlled JavaScript through canonicalization, token bytes, M64 transport, hydration, and an isolated browser test.
          
          
            Dark Star raster example
            Run the compact deterministic raster engine that reconstructs the larger Dark Star image from a small program and parameters.
          
          
            M64 hydrator
            Load an M64 artifact, hydrate it back into its controlled source form, and execute the declared entry point.
          
          
            Polygon artifact carrier
            Publish and retrieve exact artifact bytes through Polygon transaction calldata with an injected EVM wallet.
          
        

      

    


    

      

        
Tools

        
The support tools stay separate. The main page should control transactions, not become a drawer full of knives.


        
Identity / key capture / custody

        

          
            Create or recover Chisel identity
            Generate twelve recovery words locally, verify that you wrote them down, and derive the versioned public Chisel identity without sending private material to FileProxy or another application.
          
          
            Broadcast key capture
            Tablet/phone scanner for four left-to-right colored key stickers, scanned-key library, multi-chain addresses, red private-key QR, direct-printer/PNG handoff, and return to Chisel.
          
          
            Legacy QR / WIF scanner
            Older linear scanner: assemble four 16-hex stickers or a full WIF, verify one selected chain, then load it back into Chisel.
          
        


        
General tools

        

          
            Physical records / Daisy catalog
            Scan or enter a folder label. Open its private catalog through your FileProxy, searching the current ISO year and then earlier years.
          
          
            Recast video
            Switch video layouts, add timed notes/images, and export to FFmpeg with original audio.
          
          
            eCash notes / IPFS pointers in Zorkmid
            Use a printed eCash ID, prepare a native XEC note with Chisel, review its fee and change, then explicitly broadcast.
          
          
            Key and image printer
            Print key receipts or image files directly to the CTP500 over Bluetooth; save the same black-and-white image.
          
          
            CTP500 printer diagnostics
            Print a diagnostic receipt with transfer timings from your phone, then save its PNG.
          
          
            M64 artifact workbench
            Canonicalize, crush, encode, hydrate, and test compact controlled-JavaScript artifacts, including the Dark Star example.
          
          
            MacDougall resolver
            Resolve and inspect MacDougall-style encoded references with the standalone browser tool.
          

          
            2×2 label builder
            Build printable CertLedger / RVN labels with SHA-256 Base64 and txid QR fields.
          
          
            Display portal
            Render base58-color image chords from tx JSON, pasted JSON, or Digibyte explorer data.
          
          
            Browser self-test
            Run fixture, draft, send-lock, Portal boot, and static-data checks before a demo.
          
          
            Demo mode notes
            Click-through route for showing Chisel without starting with the old Decode page or a live broadcast.
          
          
            Legacy transaction decoder
            Old single-transaction inspector. Portal is the normal reader; use this when debugging txid-named fixtures or raw output decoding.
          
          
            qrField label tool
            Generate printable QR-coded field identifiers and physical entry-point labels.
          
          
            QR Label Stager
            Stage Avery 5160 labels with a medium QR, two explanatory text fields, fixed or URL-plus-random-suffix payloads, and FileProxy persistence.
