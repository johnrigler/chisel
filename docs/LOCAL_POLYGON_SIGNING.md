# Local Polygon signing
Choose Chisel local WIF (Polygon) in Send or the YouTube driver, then select the local signing method in the EVM workbench. Enter a Base58Check WIF, connect, check the derived address and POL balance, review the calldata and maximum fee, and explicitly approve the local signing action. The WIF is decoded using bundled ethers.js and is not transferred between pages or stored by this adapter. The signer is held in memory until cleared or the page is closed. The initial RPC is the public https://polygon.drpc.org endpoint; the private Mogwai dRPC key stays on the server and is not used by this release. A server-side authenticated relay is separate work. Reusing a private key across chains links the accounts if they are correlated and increases compromise impact. Use trusted builds and a dedicated low-balance key for first testing. No new on-chain envelope or contract is introduced.
