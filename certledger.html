What this means

If this page was opened from a CertLedger QR label, the paper in front of you is intended to correspond to a byte-exact PDF whose SHA-256 fingerprint is recorded or referenced in a public Litecoin transaction.

The ledger entry does not prove that every statement in the document is true. It provides a durable public reference for document identity, chronology, and later integrity checking.

In other words: conventional legal process says what was sent and received; CertLedger adds a public cryptographic reference to the exact digital artifact.

Available mirrors

CertLedger records are intended to survive any one web host. GitHub Pages, IPFS, rigler.org, Nerd Coffee, or another static host can publish the same Chisel view.

Future CertLedger location records can publish the latest IPFS CID and additional mirrors on-ledger. A reader arriving through an older mirror can then suggest a newer verified location without making that location the source of truth.
