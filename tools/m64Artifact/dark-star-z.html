Publish via Pinata

Pinata v3 uses a JWT. This is a per-session field; Chisel does not save the token in localStorage, the artifact, the URL, or the repository. A browser page holding a JWT can still expose it if the page is compromised. For stronger isolation, use a short-lived signed upload URL or a local credential broker.
