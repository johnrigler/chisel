Second-level packed M64 dictionary


Symbol 62 is the ASCII escape, followed by two six-bit values making an ASCII byte. Symbol 63 identifies an extended dictionary entry using one or more six-bit index digits. Entries are themselves packed M64 streams and may reference earlier entries.


The EVM ABI supplies the length of a returned bytes field, but not the number of meaningful six-bit symbols after padding. This trial tracks a symbol count for that reason, and checks decoding and recursion safety.
