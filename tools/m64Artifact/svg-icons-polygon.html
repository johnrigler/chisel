2. Request an icon

Enter a name such as home, an ordinal 0–63, or a six-bit character such as A (icon 0), B (icon 1), or a (icon 26). Prefix a digit with @ to interpret it as an M64 character (@0 = icon 52), or use #N for a literal contract entry ID. Names and characters are resolved by Chisel, not Solidity.

3. Append compressed icons (optional, costs gas)

The initial deployment has 62 text-fragment compression symbols but zero stored icons. This tool encodes the missing icon definitions with native M64 v2 and calls addSecondaryBatch(bytes[],uint32[]) in groups of up to eight. Anyone may append. Existing entries remain immutable.
