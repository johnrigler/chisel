How this works

The same video element plays throughout. Layout switches change its position and size; they do not restart playback. Use “Save cue here” after editing a panel. Saved cues replay when “Follow saved cues” is on.

FFmpeg does not render HTML. The export contains transparent PNG panels, a cue sheet, and a small Python renderer. Unzip it and run python3 render.py original.mp4 recast.mp4 with FFmpeg and ffprobe installed. Audio is stream-copied unchanged. The source video is not included in the ZIP.

This version supports plain-text and image cards. Arbitrary HTML/CSS overlays would need a browser capture step. The source image is fitted without stretching or cropping.
