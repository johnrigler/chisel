Chisel QR sticker sheet

Each sticker opens Chisel with its random eight-byte identifier (16 hex characters). Chisel can read the same ID from the link during a four-sticker key scan. Keep public page stickers separate from private-key stickers.

Print on plain paper first. Then adjust --SHEET_MARGIN_TOP, --SHEET_MARGIN_LEFT, --LABEL_WIDTH, and --LABEL_HEIGHT until the guides line up with your real label stock.

The QR opens Chisel with this network and address. The label prints the address only, without the URL. Address mode makes 20 copies and uses one QR per label.
